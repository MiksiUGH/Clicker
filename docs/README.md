# 🖱️ Django Clicker

Интерактивный веб-кликер на Django с системой авторизации, магазином цветов и сохранением прогресса в базу данных.

## 📖 Описание

Проект представляет собой веб-приложение-кликер. Пользователь может регистрироваться, авторизовываться, накапливать клики, сохранять их в базу данных, а также тратить накопленные клики на покупку цветов для оформления карточки кликера. Все взаимодействия с сервером происходят асинхронно (AJAX) без перезагрузки страницы.

## 🚀 Основные функции

- ✅ **Регистрация и авторизация** (используется кастомная модель `User` с полем `name` вместо `username`).
- ✅ **Кликер с кнопками CLICK и SAVE**: 
  - `CLICK` увеличивает локальный счетчик.
  - `SAVE` отправляет текущее количество кликов в БД через AJAX.
- ✅ **Загрузка данных при перезагрузке**: При открытии страницы счетчик и список купленных цветов подгружаются из БД.
- ✅ **Магазин цветов**: Тратьте клики на покупку цветов.
- ✅ **Смена цветов**: Возможность выбрать купленный цвет из выпадающего списка, карточка кликера мгновенно перекрашивается.
- ✅ **Автоматическое наполнение БД**: При запуске миграций автоматически создаются 3 базовых цвета (Красный, Синий, Зелёный), если их нет.
- ✅ **Адаптивный интерфейс на Bootstrap 5**.

## 🛠️ Установка и запуск

Следуйте этим шагам, чтобы запустить проект локально:

1. **Клонируйте репозиторий** и перейдите в папку проекта:
   ```bash
   cd clicker
   ```

2. **Создайте и активируйте виртуальное окружение** (рекомендуется):
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Mac/Linux:
   source .venv/bin/activate
   ```

3. **Установите зависимости** (Django и т.д.):
   ```bash
   pip install django
   ```

4. **Примените миграции** (при первом запуске автоматически создадутся цвета в БД):
   ```bash
   python manage.py migrate
   ```
   *(В терминале вы увидите сообщение: `Базовые цвета успешно созданы или уже существуют!`)*

5. *(Опционально)* Создайте суперпользователя для доступа к админке:
   ```bash
   python manage.py createsuperuser
   ```

6. **Запустите сервер**:
   ```bash
   python manage.py runserver
   ```

7. Откройте браузер и перейдите по адресу: **`http://127.0.0.1:8000/`**

## 🎮 Использование

1. **Регистрация**: Нажмите кнопку "Регистрация" и создайте аккаунт.
2. **Кликер**: Жмите на кнопку `CLICK`, чтобы увеличить счет. Нажмите `SAVE`, чтобы сохранить прогресс в БД.
3. **Магазин**: Под карточкой кликера находится блок магазина. Нажмите "Купить" на понравившемся цвете, если у вас достаточно кликов.
4. **Смена цвета**: После покупки цвета он появится в выпадающем списке "Выберите цвет". Выберите его, и фон карточки изменится.

## 📦 Стек технологий

- **Backend**: Python, Django 6.0, SQLite3.
- **Frontend**: HTML5, CSS3, Bootstrap 5, Vanilla JavaScript (ES6+).
- **Асинхронность**: Fetch API (AJAX) для запросов без перезагрузки страницы.
